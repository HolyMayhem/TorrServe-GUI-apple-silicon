# TorrServer for macOS

Небольшое нативное приложение для запуска и остановки локального TorrServer
без Терминала.

Версия 1.1 включает собственную иконку в стиле macOS Tahoe.

## Использование

1. Переместите `TorrServer.app` в папку «Программы».
2. Откройте приложение.
3. Нажмите «Выбрать…» и укажите скачанный исполняемый файл TorrServer.
4. Используйте кнопки «Запустить», «Остановить» и «Открыть Web UI».

Выбранный путь сохраняется автоматически. Если скачанный файл не имеет права
на запуск, приложение попытается добавить его самостоятельно. При выходе из
приложения запущенный им сервер будет остановлен.

Сам исполняемый файл TorrServer в приложение не включён. Это позволяет
самостоятельно выбирать и обновлять версию сервера.

## Системные требования

- macOS 12 или новее
- Apple Silicon или Intel

## Сборка исходников

Основной исходный файл находится в `Sources/main.swift`. Приложение использует
только системный AppKit и может быть собрано компилятором Swift из комплекта
Xcode или Command Line Tools.

# TorrServer for macOS

Нативное macOS-приложение для запуска и остановки локального TorrServer без
Терминала.

## Что уже есть

- Кнопки запуска, остановки и открытия `http://localhost:8090`.
- SwiftUI-popover в верхней панели macOS для быстрого управления.
- Отображение скорости TorrServer в верхней панели macOS.
- Скорость скрывается, когда сервер остановлен или текущая скорость равна нулю.
- В popover отображаются текущий или последний материал, прогресс буферизации,
  сиды, пиры и график скорости за последние 60 секунд.
- QR-код с локальным адресом Web UI для открытия с iPhone, телевизора или
  другого устройства в той же сети.
- Нативная вкладка `Библиотека`, которая работает напрямую с API TorrServer:
  список материалов, живой статус, скорость, сиды, пиры и файлы раздачи.
- Добавление magnet-ссылок, выбор нескольких `.torrent` и drag-and-drop
  torrent-файлов в окно.
- Запуск выбранного видеофайла во внешнем плеере: QuickTime, IINA, VLC,
  системное или выбранное пользователем приложение.
- Удаление материалов и автоматическое обновление библиотеки каждые 2 секунды.
- Форматы скорости `Авто`, `MB/s` и `Mbit/s`.
- Опциональные системные уведомления о запуске сервера, установленном
  обновлении и ошибках.
- Уведомления и формат скорости настраиваются только в основном окне, чтобы
  menu-bar popover оставался компактным.
- Опция `Показывать приложение только в меню баре`: Dock-иконка исчезает,
  но уже открытое окно остается на экране.
- Переключение языка через широкий двухпозиционный glass-тумблер `Russian / English`.
- По умолчанию используется язык системы.
- Выбор исполняемого файла TorrServer вручную.
- Загрузка последнего `TorrServer-darwin-arm64` из GitHub Releases.
- Автозапуск приложения при входе в macOS через LaunchAgent.
- Опция автоматического запуска сервера при открытии приложения.
- Окно `О TorrServer` с подписью `Holy Mayhem`.
- SwiftUI-интерфейс с системными Liquid Glass-кнопками на macOS Tahoe.
- Компактные нативные системные `Toggle` в стиле macOS Settings, выровненные справа.
- Единый полупрозрачный material-фон проходит под системной шапкой и визуально
  объединяет всё окно без разделительной полосы.
- Фиксированный размер окна без растягивания по горизонтали или вертикали.
- Компактная высота окна подбирается по содержимому; внешние отступы слева,
  справа и снизу составляют 17 pt.
- Крупный значок menu bar: белая молния внутри серого или зеленого круга.

## Иконка

Исходник иконки хранится в `Resources/AppIcon.iconset`. Другие исходные PNG и
готовый `.icns` в `Resources` не хранятся.

Во время сборки `Scripts/build-app.sh` использует официальный экспортёр Apple
Icon Composer (`ictool`) и генерирует `build/generated/AppIconSystemDark.icns`.
Поэтому в `.app` попадает именно вариант с тёмной superellipse-подложкой,
объёмными слоями и тенями, показанный в Icon Composer. Если Xcode с Icon Composer
не найден, используется встроенный fallback-генератор. Имя ресурса отличается
от старой версии, чтобы macOS не подставляла закэшированную светлую иконку.

## Использование

1. Соберите приложение через VS Code task `App: Build TorrServer.app` или командой:

   ```bash
   ./Scripts/build-app.sh
   ```

2. Переместите `build/app/TorrServer.app` в папку «Программы».
3. Откройте приложение.
4. Нажмите `Скачать ARM` или выберите скачанный файл TorrServer вручную.
5. Управляйте сервером из окна или из иконки в верхней панели macOS.
6. При необходимости выключите скорость галочкой `Показывать скорость в меню баре`.
7. При необходимости включите режим `Только меню бар, без значка в Dock`.
8. Выберите формат скорости и при необходимости включите системные уведомления.
9. Выберите язык внизу окна через переключатель `Russian / English`.
10. Перейдите на вкладку `Библиотека`, добавьте magnet или `.torrent`,
    выберите файл и нажмите `Смотреть`.

Выбранный путь сохраняется автоматически. Если файл TorrServer не имеет права
на запуск, приложение попытается добавить его самостоятельно.

Скорость в меню баре считается по локальной странице `http://127.0.0.1:8090/stat`.
Приложение опрашивает счетчик `BytesReadData` и показывает скорость как разницу
байт между двумя замерами.

Данные материала берутся через `POST http://127.0.0.1:8090/torrents` с
`{"action":"list"}`. Активная трансляция имеет приоритет; если её нет, popover
показывает последний добавленный материал.

## VS Code

Проект подготовлен как Swift Package Manager-пакет. Для удобной работы в VS Code
установите расширение `Swift` от Swift Server Work Group.

Полезные задачи:

- `Swift: Build` - быстрая проверка компиляции.
- `App: Build TorrServer.app` - сборка полноценного macOS-приложения.
- `App: Package ZIP` - сборка ZIP-архива в папку `dist`.

## Системные требования

- macOS 12 или новее
- Apple Silicon для автоматической загрузки `TorrServer-darwin-arm64`
- Xcode или Command Line Tools

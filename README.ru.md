# TorrServer для macOS

[English](README.md) | **Русский**

Нативное приложение для управления TorrServer на Mac с Apple Silicon без
использования Терминала.

## Возможности

- Запуск, остановка, обновление и диагностика TorrServer.
- Добавление magnet-ссылок и `.torrent`-файлов в нативную библиотеку.
- Поиск раздач через Jackett.
- Воспроизведение в IINA, VLC, Infuse или системном плеере.
- Управление, скорость передачи и активная трансляция в меню баре.
- Интерфейс на русском и английском языках.

## Установка

Скачайте DMG из раздела Releases, откройте его и перетащите `TorrServer.app`
в папку `Applications`.

Исполняемый файл `TorrServer-darwin-arm64` для Apple Silicon уже входит в
приложение. Jackett требуется только для встроенного поиска.

## Системные требования

- macOS 12 или новее.
- Mac с Apple Silicon.
